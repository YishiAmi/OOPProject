JRPG CLASS LIBRARY · API REFERENCE

Game systems,
without the screen.

RpgLibrary is a reusable .NET class library for turn-based combat, world exploration, quests, shops, items, and player state. Its public APIs return data and outcomes that a WinForms—or any other—front end can render.

SYSTEM DESIGN

One facade, four focused namespaces

WinForms coordinates player-level operations through GameManager. Subsystems exchange only shared contract types, keeping the DLL portable and preventing circular dependencies.

F

Facade

Forms request top-level game actions from one coordinator instead of mutating several subsystems.

C

Contracts

ICombatant and IShopItem carry shared behavior across namespace boundaries.

R

Result APIs

World operations return status-rich records that the UI can translate into labels, dialogs, or animations.

INTEGRATION GUIDE

Connect the facade to WinForms

Keep controls in the demo and state transitions in the DLL. Translate result records into presentation.

MainForm.cs
private void BuyButton_Click(object? sender, EventArgs e)
{
    PurchaseResult result = gameManager.BuyItem(selectedSlot);

    statusLabel.Text = result.Status switch
    {
        PurchaseStatus.Success =>
            $"Purchased {result.Item.Name}.",
        PurchaseStatus.InsufficientGold =>
            "You do not have enough gold.",
        PurchaseStatus.OutOfStock =>
            "That item is out of stock.",
        _ => "The purchase could not be completed."
    };

    goldLabel.Text = $"{result.GoldRemaining} G";
}
